📱 iOS Daily English - Day 31

Equatable
- A protocol that lets a type check whether two of its values are equal with `==`.
- Example: "`Point` is Equatable, so I can check `a == b` in the unit test."

Hashable
- A protocol that lets a type be stored in a set or used as a dictionary key.
- Example: "I made `Tag` Hashable, so we can keep tags in a `Set`."

Comparable
- A protocol that lets a type order its values with `<` so they can be sorted.
- Example: "`Level` is Comparable, so `sorted()` works without a closure."
