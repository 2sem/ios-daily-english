📱 iOS Daily English - Day 220

ModelConfiguration
- An object that describes how SwiftData stores your models, such as whether it uses the disk.
- Example: "Pass a ModelConfiguration to the container."

In-Memory Store
- A store that keeps data only in memory, so it disappears when the app quits.
- Example: "Tests use an in-memory store, so nothing stays on disk."

Unique Constraint
- A rule that allows only one stored item with a given value, such as one account per email.
- Example: "Add a unique constraint on the email field."
