📱 iOS Daily English - Day 287

Loading State
- A value, often an enum, that says whether a screen is idle, loading or done.
- Example: "Add a loading state so the spinner shows."

MainActor View Model
- An observable class marked @MainActor, so every change to its screen state happens on the main actor.
- Example: "Make the MainActor view model own the screen state."

MainActor.run
- A static method that runs a closure on the main actor and gives back its result.
- Example: "Use MainActor.run to hop back for one update."
