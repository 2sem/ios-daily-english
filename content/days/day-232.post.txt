📱 iOS Daily English - Day 232

Build Setting
- A single named value, such as the Swift version, that controls how Xcode builds a target.
- Example: "Change the build setting for the Swift version."

xcconfig
- A plain text file that stores build settings, so you can keep them outside the Xcode project file.
- Example: "Each environment has its own xcconfig file."

Build Variable
- A placeholder in a plist file that Xcode replaces with the value of a build setting.
- Example: "The plist reads the host from a build variable."
