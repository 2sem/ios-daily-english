📱 iOS Daily English - Day 282

@concurrent
- An attribute that makes an async function run off the caller's actor, on the background pool.
- Example: "Mark the image resize as @concurrent."

Nonisolated Nonsending
- A mode for an async function that keeps it running on the caller's actor instead of hopping away.
- Example: "A nonisolated nonsending function stays on the main actor."

Caller Isolation
- The actor a function was called from, which a nonsending async function keeps using.
- Example: "The helper inherits the caller isolation."
