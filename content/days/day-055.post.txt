📱 iOS Daily English - Day 55

Regex
- A pattern that describes the shape of text, used to find or check matching strings.
- Example: "Use a Regex to pull the order number out of the email."

Capture Group
- A part of a regex inside parentheses that saves the text it matched so you can use it.
- Example: "Wrap the name in a Capture Group, then read it as `m.1`."

Regex Builder
- A way to write a regex as readable Swift code with names like `OneOrMore`, from the RegexBuilder module.
- Example: "Switch to Regex Builder, so the pattern reads like Swift."
