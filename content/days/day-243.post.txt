📱 iOS Daily English - Day 243

Application Support Directory
- The folder where your app stores important files it needs, which users never see.
- Example: "Save the notes file in the application support directory."

Caches Directory
- The folder for files you can download or build again, which the system may delete when space is low.
- Example: "Put the thumbnails in the caches directory."

Backup Exclusion
- A flag on a file that tells the system not to copy it into the device backup.
- Example: "Use backup exclusion for files you can download again."
