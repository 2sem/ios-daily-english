📱 iOS Daily English - Day 275

Task Priority
- A hint that tells the system how urgent a task is, such as high, medium or low.
- Example: "Give the image import a low task priority."

currentPriority
- A static property that tells you the priority of the task running right now.
- Example: "Print currentPriority to see what the task got."

Priority Inheritance
- The rule that a new child task starts with the same priority as the task that created it.
- Example: "Thanks to priority inheritance, the child is urgent too."
