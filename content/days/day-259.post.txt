📱 iOS Daily English - Day 259

Task
- A unit of `async` work that runs on its own and can be awaited for its result.
- Example: "Create a Task to start the async work."

Executor
- An object that decides where and when a task's code runs, such as a queue or a thread.
- Example: "An executor decides where the code runs."

Cooperative Thread Pool
- A small, fixed group of threads that Swift shares among all `async` work.
- Example: "The cooperative thread pool never grows too big."
