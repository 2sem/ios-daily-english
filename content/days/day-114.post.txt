📱 iOS Daily English - Day 114

Dynamic Type
- A setting that lets users make text bigger or smaller in every app.
- Example: "Turn on Dynamic Type in Settings and check that nothing is cut off."

Text Style
- A named font role, such as body or title, that grows with the user's text size.
- Example: "Use a Text Style instead of a fixed font size."

Scaled Font
- A custom font that you scale with `UIFontMetrics`, so it follows the user's text size.
- Example: "Our brand font needs a Scaled Font to support larger text."
