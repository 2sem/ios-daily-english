📱 iOS Daily English - Day 228

Offline-First
- A design where the app works from local data first and talks to the server when it can.
- Example: "An offline-first app never shows a blank screen."

Optimistic Update
- Showing a change on screen right away, before the server confirms it.
- Example: "An optimistic update makes the like button feel instant."

Sync Queue
- A waiting list of changes saved on the device, which the app sends to the server later.
- Example: "The sync queue sends the edits when we are online."
