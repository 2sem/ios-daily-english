📱 iOS Daily English - Day 9

Protocol
- A list of rules that says what properties and methods a type must have.
- Example: "Let's write a protocol, so every screen follows the same rules."

Extension
- A way to add new methods to a type you already have, without editing its original code.
- Example: "I added a small extension to Int, so we can double any number."

Protocol Conformance
- When a type promises to follow a protocol by providing everything the protocol asks for.
- Example: "The compiler shows an error because Bird is missing its protocol conformance."
