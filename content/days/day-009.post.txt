📱 iOS Daily English - Day 9

Struct
- A type that groups related values together, and every copy you make is independent of the others.
- Example: "I made the user profile a struct, so changing a copy does not touch the original."

Class
- A type that groups data and actions together, and it can inherit from a parent type.
- Example: "The view controller is a class, because UIKit needs it to inherit from UIViewController."

Reference Type
- A type where many variables point to the same single instance, so a change through one variable shows up in all of them.
- Example: "Because it is a reference type, both screens see the update as soon as one of them changes it."
