📱 iOS Daily English - Day 93

UserDefaults
- A simple key-value store for small settings, like a theme choice or a flag, that stays across launches.
- Example: "Keep the dark mode switch in UserDefaults, it's just one Bool."

File Manager
- The Foundation object you use to create, move, check and delete files and folders.
- Example: "Ask File Manager if the export exists before you share it."

Documents Directory
- The folder in your app's sandbox for files the user creates, which is included in backups.
- Example: "Save the drawings to the Documents Directory, so they survive updates and get backed up."
