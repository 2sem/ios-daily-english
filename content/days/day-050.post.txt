Conditional Conformance
- A way for a generic type to conform to a protocol only when its type parameter also conforms.
- Example: "Thanks to Conditional Conformance, an array of `Int` is Equatable."

Primary Associated Type
- An associated type you can fill in with angle brackets after a protocol name, like `Collection<Int>`.
- Example: "With a Primary Associated Type, we can write `some Collection<Int>`."

Parameter Pack
- A generic feature, written with `each` and `repeat`, that lets a function take any number of values of different types.
- Example: "A Parameter Pack lets `log` take an `Int`, a `String` and a `Bool` at once."
