📱 iOS Daily English - Day 162

Searchable
- A modifier that adds a search field to a screen and gives you the text the user types.
- Example: "Add Searchable, so users can find a name."

Refreshable
- A modifier that lets the user pull a list down to run async code that loads new data.
- Example: "Add Refreshable, so users can pull down to update."

Search Suggestions
- A list of ideas that appears under the search field while the user types.
- Example: "Show Search Suggestions for the most popular names."
