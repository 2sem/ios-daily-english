📱 iOS Daily English - Day 51

Exhaustive Switch
- A `switch` that covers every possible case, so it needs no `default`.
- Example: "Keep it an Exhaustive Switch, so the compiler tells us about new cases."

Unknown Default
- A case written `@unknown default` that handles enum cases added in the future but still warns about current ones you missed.
- Example: "Add an Unknown Default, because Apple may add new states later."

Frozen Enum
- A public enum marked `@frozen` that promises it will never get new cases.
- Example: "`Optional` is a Frozen Enum, so two cases are always enough."
