📱 iOS Daily English - Day 80

Whole Module Optimization
- A build mode where the compiler optimizes all files of a module together.
- Example: "Release builds use Whole Module Optimization, so they take longer but run faster."

Generic Specialization
- When the optimizer copies a generic function for one exact type, so it runs faster.
- Example: "Generic Specialization only happens with optimization on, so measure in a release build."

Inlinable
- An attribute, written `@inlinable`, that puts a public function's body in the module's interface so other modules can optimize it.
- Example: "Mark the helper Inlinable, the app calls it from another module in a hot loop."
