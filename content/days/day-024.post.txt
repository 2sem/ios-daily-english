📱 iOS Daily English - Day 24

Default Parameter
- A parameter that has a preset value, used when the caller passes nothing for it.
- Example: "Use default parameters so callers can skip values that rarely change."

Variadic Parameter
- A parameter that accepts zero or more values of the same type, written with three dots after the type.
- Example: "Use variadic parameters so we can pass any number of scores."

In-Out Parameter
- A parameter that lets a function change the caller's variable, marked with `inout`.
- Example: "Use in-out parameters when the function must update the caller's variable."
