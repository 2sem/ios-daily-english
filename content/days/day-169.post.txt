📱 iOS Daily English - Day 169

EnvironmentKey
- A protocol for a key that gives your own value a default in the environment.
- Example: "Add an EnvironmentKey for the theme."

PreferenceKey
- A protocol for a key that lets a child view send a value up to its parent.
- Example: "Use a PreferenceKey to send the width to the parent."

onPreferenceChange
- A modifier that runs code in a parent view when a preference value changes.
- Example: "Read the width in onPreferenceChange."
