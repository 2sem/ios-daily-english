📱 iOS Daily English - Day 75

Shallow Copy
- A copy that duplicates only the outer value, so the class instances inside are still shared with the original.
- Example: "Copying the cart is only a Shallow Copy, the items are still the same objects."

Deep Copy
- A copy that also duplicates every object inside, so changing the copy never touches the original.
- Example: "Make a Deep Copy before editing, or the undo history changes too."

NSCopying
- A Foundation protocol a class adopts to say how a new, separate copy of it is made in `copy(with:)`.
- Example: "Our `Document` class adopts NSCopying, so every copy is a separate instance."
