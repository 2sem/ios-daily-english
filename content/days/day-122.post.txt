📱 iOS Daily English - Day 122

Interface Orientation
- Whether the screen is shown upright (portrait) or sideways (landscape).
- Example: "Lock the Interface Orientation to portrait for the camera screen."

Size Class
- A simple label, compact or regular, for the width or height available to your app.
- Example: "Check the Size Class before you show the sidebar."

Adaptive Layout
- A layout that changes to fit different screen sizes and orientations.
- Example: "We need an Adaptive Layout so the screen works on iPad too."
