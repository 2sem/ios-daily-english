📱 iOS Daily English - Day 77

Explicit Self
- Writing `self.` in front of a property inside an escaping closure, which a class requires so you can see the capture.
- Example: "The compiler wants Explicit Self here, because this closure outlives the method."

Weak Self
- Writing `[weak self]` in a closure's capture list, so the closure does not keep its object alive.
- Example: "Use Weak Self in that network callback, or the view model never gets freed."

Implicit Self
- Leaving out `self.` inside a closure, allowed after `[self]` in the capture list or after `guard let self`.
- Example: "After `guard let self`, Implicit Self is fine, so drop all those `self.` prefixes."
