📱 iOS Daily English - Day 263

For-Await Loop
- A loop written as `for await` that waits for each next value to arrive.
- Example: "A for-await loop waits for each value."

AsyncSequence
- A sequence whose values arrive over time, so you read them with `await`.
- Example: "An AsyncSequence delivers values over time."

AsyncStream
- A ready-made stream of values over time that you fill with `yield` and close with `finish`.
- Example: "Build an AsyncStream to publish location updates."
