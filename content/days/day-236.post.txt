📱 iOS Daily English - Day 236

Remote Config
- A service that sends settings to your app from a server, so you can change them without an update.
- Example: "Change the retry count with remote config."

Fallback Value
- A safe value the app uses when the server value is missing or has not arrived yet.
- Example: "The app uses the fallback value offline."

A/B Test
- An experiment that shows two versions of a feature to different groups of users to see which works better.
- Example: "Run an A/B test on the new button."
