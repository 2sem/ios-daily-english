📱 iOS Daily English - Day 27

Enumerated
- A collection method that gives you each item together with its position number.
- Example: "Use enumerated to show the step number next to each task."

Zip
- A function that walks through two sequences at the same time and pairs their items.
- Example: "Use zip to match each name with its score."

Higher-Order Function
- A function that takes another function as input or returns one.
- Example: "Map is a higher-order function because it takes a closure."
