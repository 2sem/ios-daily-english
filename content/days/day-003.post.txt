📱 iOS Daily English - Day 3

Function
- A named block of code that does one job and can be run again whenever you call it by name.
- Example: "I moved the date formatting into a function so both screens can reuse it."

Parameter
- A named input that a function declares so the caller can pass a value in.
- Example: "The method takes one parameter, the user ID, so pass it the ID of the signed-in user."

Argument Label
- A word written before a value in a function call that tells the reader what that value is for.
- Example: "Add an argument label here so the call reads like a sentence at the call site."
