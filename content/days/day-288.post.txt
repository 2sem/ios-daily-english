📱 iOS Daily English - Day 288

Async Test
- A test method marked async, so it can use await directly in XCTest.
- Example: "Write an async test instead of using a callback."

XCTestExpectation
- An object that stands for something that must happen, such as a callback, before a test can finish.
- Example: "Create an XCTestExpectation for the callback."

fulfillment(of:)
- An async XCTestCase method that waits for expectations to finish without blocking the thread.
- Example: "Await `fulfillment(of:)` in an async test."
