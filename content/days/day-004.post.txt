📱 iOS Daily English - Day 4

Condition
- A Bool expression that Swift checks to decide which path the code takes.
- Example: "The if only runs when the condition is true, so log the value to see why it never fires."

guard
- A Swift statement that checks a condition and must leave the current scope if the check fails.
- Example: "Use a guard at the top of the method so we bail out when the user is not signed in."

Early Exit
- A style of returning from a function as soon as a requirement fails, so the main code stays unindented.
- Example: "I rewrote the nested ifs as an early exit, and now the happy path reads straight down."
