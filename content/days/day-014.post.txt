📱 iOS Daily English - Day 14

Method
- A function that lives inside a type and works with that type's data.
- Example: "Add a method to `Counter`, so it can show its own count."

Mutating Method
- A method on a struct that is allowed to change the struct's own properties.
- Example: "Mark it as a mutating method, so `add` can change `count`."

Type Method
- A method that you call on the type itself, not on one value of it.
- Example: "Make it a type method, so you call `Math.double(4)` without a value."
