📱 iOS Daily English - Day 277

measure
- A clock method that runs a closure and returns how long it took as a Duration.
- Example: "Wrap the slow call in measure."

Instant
- A single point in time on a clock, which you can compare or move by a Duration.
- Example: "Store the start Instant, then compare it later."

SuspendingClock
- A clock that stops counting while the device sleeps, so it shows time spent awake.
- Example: "Use SuspendingClock to time only the active work."
