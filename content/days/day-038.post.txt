📱 iOS Daily English - Day 38

ARC
- A system in Swift that counts the references to each class instance and frees it when none are left.
- Example: "ARC freed `photo` as soon as I set it to `nil`."

Strong Reference
- A normal reference that keeps a class instance alive for as long as the reference exists.
- Example: "`b` is still a Strong Reference, so the photo stays in memory."

Retain Cycle
- A problem where class instances hold Strong References to each other, so none of them is ever freed.
- Example: "`deinit` never runs, so I think we have a Retain Cycle."
