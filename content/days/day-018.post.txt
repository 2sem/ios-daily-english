📱 iOS Daily English - Day 18

Optional Chaining
- A way to read a property or call a method on an optional, and get nil if the optional is nil.
- Example: "Use optional chaining, so a missing `user` gives nil, not a crash."

Nil-Coalescing Operator
- The `??` operator, which gives a default value when an optional is nil.
- Example: "Use the nil-coalescing operator, so a missing nickname becomes "Guest"."

Force Unwrapping
- Using `!` to take the value out of an optional, which crashes if it is nil.
- Example: "Avoid force unwrapping here, because `user` can be nil and the app would crash."
