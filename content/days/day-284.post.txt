📱 iOS Daily English - Day 284

Completion Handler
- A closure you pass to a function, which the function calls later when its work is done.
- Example: "The old SDK takes a completion handler."

Callback Bridging
- Wrapping an old callback API in an async function, so callers can simply use await.
- Example: "Callback bridging removes the nested closures."

Resume Once
- The rule that a continuation must be resumed exactly one time, never zero times and never twice.
- Example: "Check every branch for resume once."
