📱 iOS Daily English - Day 7

Closure
- A block of code you can store in a variable or pass to a function and run later.
- Example: "I passed a closure to the sort method so it knows how to compare two names."

Trailing Closure
- A closure written after the function's parentheses instead of inside them, which makes the call easier to read.
- Example: "I used a trailing closure on map, so the code reads cleanly with no extra parentheses."

Capture List
- A list in square brackets at the start of a closure that says which outside values the closure keeps, and how it keeps them.
- Example: "I added a capture list with weak self so the closure does not keep the view controller alive."
