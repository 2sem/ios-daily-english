📱 iOS Daily English - Day 92

Target Action
- A pattern where a control calls a chosen method on a chosen object when an event happens.
- Example: "Wire the save button with Target Action in `viewDidLoad`."

Gesture Recognizer
- An object you attach to a view to detect touches like taps, swipes or pinches.
- Example: "Add a Gesture Recognizer for the double tap, the image should zoom."

Responder Chain
- The line of objects UIKit passes an event or action along until one of them handles it.
- Example: "Leave the target `nil`, the Responder Chain will find the editor."
