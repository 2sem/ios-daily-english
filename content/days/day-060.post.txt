📱 iOS Daily English - Day 60

Implicitly Unwrapped Optional
- An optional written with an exclamation mark, like `String!`, that Swift unwraps for you every time you use it.
- Example: "That Implicitly Unwrapped Optional crashed because setup never ran."

Optional Map
- Calling `map` on an optional, so the closure changes the value inside, and `nil` simply stays `nil`.
- Example: "Use Optional Map here instead of unwrapping, then wrapping again."

Optional Pattern
- A pattern like `x?` in `if case` or `for case` that matches only when there is a value, and unwraps it.
- Example: "Loop with an Optional Pattern, so the nil scores are skipped."
