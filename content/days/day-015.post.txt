📱 iOS Daily English - Day 15

Type Property
- A property that belongs to the type itself, so every value of that type shares it.
- Example: "Make it a type property, so every `Game` shares one `maxPlayers`."

Subscript
- A shortcut that lets you read an item from a type with square brackets.
- Example: "Add a subscript to `Team`, so you can write `team[1]`."

Deinitializer
- A block of code in a class that runs just before the object is removed from memory.
- Example: "Put the cleanup in a deinitializer, so it runs when `Session` goes away."
