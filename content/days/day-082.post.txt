📱 iOS Daily English - Day 82

View Controller
- An object that manages one screen of an app: its views and what happens when the user taps them.
- Example: "Each tab has its own View Controller, so keep them small."

viewDidLoad
- The method UIKit calls once, after a screen's view has been loaded into memory.
- Example: "Add the subviews in viewDidLoad, they only need to be created once."

viewWillAppear
- The method UIKit calls every time a screen's view is about to appear.
- Example: "Reload the list in viewWillAppear, so it's fresh when the user comes back."
