📱 iOS Daily English - Day 22

Break
- A control-flow statement that ends a loop immediately and moves on to the code after it.
- Example: "Use breaks to stop the loop as soon as `score` is above 7."

Continue
- A control-flow statement that skips the rest of the current run and starts the next one.
- Example: "Use continues to skip empty names and keep the loop going."

Labeled Statement
- A control-flow statement that gives a loop a name, so `break` or `continue` can target that loop.
- Example: "Use labeled statements to leave the outer loop from inside the inner loop."
