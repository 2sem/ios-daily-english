📱 iOS Daily English - Day 216

Background Context
- A second context that does slow work on a background queue, so the screen stays smooth.
- Example: "Import the data in a background context."

Merge Policy
- A rule that decides which version wins when two contexts change the same object.
- Example: "Set a merge policy so the newest change wins."

NSFetchedResultsController
- A helper that watches a fetch request and tells a table view when the results change.
- Example: "An NSFetchedResultsController keeps the list in sync."
