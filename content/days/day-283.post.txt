📱 iOS Daily English - Day 283

Top-Level Code
- Statements written directly in main.swift outside any function, which run in order when the program starts.
- Example: "Top-level code is fine for a quick script."

Top-Level Await
- Using await directly in top-level code, with no async function around it.
- Example: "Top-level await keeps the script short."

Async Main
- A main entry point marked async, so the whole program can await from its first line.
- Example: "Make main async, then await the setup."
