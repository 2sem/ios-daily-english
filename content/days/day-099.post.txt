📱 iOS Daily English - Day 99

Interface Builder
- The visual editor in Xcode where you drag and drop views to design a screen.
- Example: "Do the simple screens in Interface Builder, it takes a minute."

Xib
- A file that stores the layout of one view or screen, loaded at runtime as a nib.
- Example: "Each cell has its own Xib, so the storyboard stays small."

Programmatic UI
- Building your screens in Swift code instead of dragging views in a visual editor.
- Example: "We use Programmatic UI, so merge conflicts are easy to read."
