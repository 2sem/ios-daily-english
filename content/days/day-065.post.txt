Generic Typealias
- A `typealias` with its own type parameter, like `Pair<T>`, that gives a generic type a shorter name.
- Example: "Add a Generic Typealias, so we stop writing the full dictionary type everywhere."

Constrained Extension
- An extension with a `where` clause, so its methods exist only when the type meets that condition.
- Example: "Put `total` in a Constrained Extension, so only arrays of `Int` get it."

Generic Subscript
- A subscript with its own type parameter, so the caller decides which type comes back.
- Example: "With a Generic Subscript, one lookup returns an `Int` or a `String`."
