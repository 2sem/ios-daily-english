📱 iOS Daily English - Day 141

NavigationStack
- A container that lets the user move forward through screens and go back.
- Example: "Wrap the home screen in a NavigationStack."

NavigationLink
- A view that the user taps to go to another screen.
- Example: "Add a NavigationLink to the detail screen."

Navigation Path
- A list of values that stores which screens are on the stack.
- Example: "Append a value to the Navigation Path to open a screen."
