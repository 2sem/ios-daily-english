📱 iOS Daily English - Day 48

Tuple Pattern
- A pattern that matches several values at once by listing them in parentheses.
- Example: "Use a Tuple Pattern to check the status code and the message together."

Value-Binding Pattern
- A pattern that matches a value and also gives part of it a new name with `let` or `var`.
- Example: "A Value-Binding Pattern pulls the width out, so we can print it."

Pattern Matching Operator
- The `~=` operator that checks whether a value fits a pattern, which every `case` uses behind the scenes.
- Example: "The Pattern Matching Operator is why a range works in a `case`."
