📱 iOS Daily English - Day 17

Designated Initializer
- An initializer that sets every property of a class and is the main way to create it.
- Example: "Write a designated initializer, so `Chat` sets every property."

Convenience Initializer
- An initializer that is a shortcut and calls another initializer of the same class.
- Example: "Add a convenience initializer, so `Chat()` works with no arguments."

Required Initializer
- An initializer marked with a keyword that every subclass must also write.
- Example: "Mark it as a required initializer, so every subclass must write it."
