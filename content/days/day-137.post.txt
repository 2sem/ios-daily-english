📱 iOS Daily English - Day 137

List
- A scrolling view that shows rows of data in a column.
- Example: "Show the notes in a List."

ForEach
- A view that creates one view for each item in a collection.
- Example: "Use ForEach to create a row for every note."

Section
- A group of rows with an optional header and footer.
- Example: "Put the pinned notes in their own Section."
