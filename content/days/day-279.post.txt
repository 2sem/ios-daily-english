📱 iOS Daily English - Day 279

Atomic Counter
- A number kept in an atomic type that many tasks can add to safely.
- Example: "An atomic counter is enough for simple stats."

Memory Ordering
- A setting on an atomic call that says how strictly other threads must see its changes.
- Example: "Pick the weakest memory ordering that is still correct."

Compare and Exchange
- An atomic step that changes a value only if it still equals the one you expected.
- Example: "Use compare and exchange to claim the job once."
