📱 iOS Daily English - Day 278

Mutex
- A lock from the Synchronization module that lets only one thread use a protected value at a time.
- Example: "Store the shared array inside a Mutex."

withLock
- A method that locks a mutex, runs your closure on the protected value and then unlocks it.
- Example: "Read the count inside withLock, never outside."

Atomic
- A type that lets many threads read and change a simple number safely, with no lock.
- Example: "Use an Atomic for a simple hit counter."
