📱 iOS Daily English - Day 198

Singleton
- A class that has exactly one shared instance for the whole app.
- Example: "The settings object is a singleton, so avoid changing it in tests."

Factory Method
- A method that creates and returns objects so the caller skips the initializer.
- Example: "Add a factory method that builds the preview data."

Adapter Pattern
- A pattern that wraps an object so it fits the interface another part expects.
- Example: "The adapter pattern lets us use the old SDK in new code."
