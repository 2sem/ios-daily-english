📱 iOS Daily English - Day 256

Critical Section
- A part of the code that only one thread may run at a time.
- Example: "Keep the critical section short."

NSLock
- A lock object that lets one thread at a time enter protected code and makes the others wait.
- Example: "Protect the counter with an NSLock."

os_unfair_lock
- A fast, low-level lock from the `os` module that must stay at one memory address.
- Example: "Never copy an os_unfair_lock value."
