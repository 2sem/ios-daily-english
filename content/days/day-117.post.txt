📱 iOS Daily English - Day 117

Active State
- The state when the app is on screen and the user can use it.
- Example: "Start the animation only in the Active State."

Inactive State
- The short state when the app is on screen but cannot take input, for example during a call.
- Example: "The app enters the Inactive State when a call comes in."

Background State
- The state when the app is off screen but can still run code.
- Example: "Save the draft when the app enters the Background State."
