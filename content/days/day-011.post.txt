📱 iOS Daily English - Day 11

Generic
- Code that works with any type, so you write it once instead of once for each type.
- Example: "We made the cache generic, so it can store images, users, or anything else."

Type Parameter
- A placeholder name, like T, for a type that is filled in later when the code is used.
- Example: "In this function, T is the type parameter, and it becomes Int when we pass in numbers."

Generic Constraint
- A rule that limits a generic to types that meet a requirement, such as conforming to a protocol.
- Example: "I added a generic constraint so the function only accepts types that are Equatable."
