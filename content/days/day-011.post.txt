📱 iOS Daily English - Day 11

Throw
- A keyword that stops a function and sends out an error.
- Example: "Throw an error if the password is wrong."

Try
- A keyword you write before a call that can throw an error.
- Example: "Add try before this call, because it can fail."

Do-Catch
- A block that runs risky code and handles any error it throws.
- Example: "Wrap it in do-catch, so the app does not crash."
