📱 iOS Daily English - Day 13

lazy
- A keyword that waits to create a property until the first time your code uses it.
- Example: "I made the image loader lazy, so it is not created until the first screen needs it."

Computed Property
- A property that does not store a value, but calculates it each time you read it.
- Example: "The full name is a computed property, so it always matches the first name and last name."

Property Observer
- Code that runs right before or right after the value of a property changes.
- Example: "I added a property observer to score, so the label updates every time the number changes."
