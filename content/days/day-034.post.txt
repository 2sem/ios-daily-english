📱 iOS Daily English - Day 34

Private
- A keyword that hides a property or method from all code outside its own type.
- Example: "I made `cash` Private, so only `Wallet` can read it."

Internal
- A keyword for the default level that lets any code in your own module use a type, but hides it from other modules.
- Example: "`Tab` is Internal by default, so the whole app can use it."

Public
- A keyword that lets code in other modules use a type or member, as long as it is marked with it.
- Example: "I made `Badge` Public so the other framework can use it."
