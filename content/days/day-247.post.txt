📱 iOS Daily English - Day 247

Siri Shortcut
- A saved action that the user can start by voice or from the Shortcuts app.
- Example: "Add a Siri shortcut for the coffee order."

Invocation Phrase
- The short phrase a user says to Siri to start a saved action.
- Example: "Keep the invocation phrase short and easy to say."

Prediction Eligibility
- A setting that lets Siri suggest an activity to the user at a useful moment.
- Example: "Turn on prediction eligibility for the order screen."
