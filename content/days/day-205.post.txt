📱 iOS Daily English - Day 205

Data Task
- A URLSession task that loads the reply into memory as Data.
- Example: "Use a data task to load the small JSON file."

HTTPURLResponse
- The reply type that gives you the status code and headers of an HTTP reply.
- Example: "Cast the response to HTTPURLResponse to read the status."

Download Task
- A task that saves a large reply to a file on disk instead of keeping it in memory.
- Example: "Use a download task for the video file."
