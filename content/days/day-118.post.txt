📱 iOS Daily English - Day 118

viewDidAppear
- A method that runs after the screen is fully visible.
- Example: "Start the timer in viewDidAppear, so it begins when the user can see the screen."

viewWillDisappear
- A method that runs just before the screen goes away.
- Example: "Stop the timer in viewWillDisappear, so it does not run on a hidden screen."

viewDidLayoutSubviews
- A method that runs after the view has set the size and position of its subviews.
- Example: "Set the gradient frame in viewDidLayoutSubviews, because the final size is known there."
