📱 iOS Daily English - Day 21

For-In Loop
- A loop that runs its body once for each item in a collection or range.
- Example: "Use a for-in loop to print each name in the `names` array."

While Loop
- A loop that checks a condition first, then runs its body again and again while the condition is true.
- Example: "Use a while loop to count down while `count` is above zero."

Repeat-While Loop
- A loop that runs its body first, then checks a condition to decide whether to run again.
- Example: "Use a repeat-while loop, so the login code runs at least once."
