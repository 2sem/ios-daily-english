📱 iOS Daily English - Day 215

Persistent Store
- The file on disk where the framework keeps all of the saved objects.
- Example: "The persistent store is a single SQLite file."

Faulting
- A lazy loading trick that keeps a light placeholder until you actually read the object's data.
- Example: "Faulting keeps memory low because data loads only when needed."

Lightweight Migration
- An automatic update of the saved data to a new model, when the changes are simple, such as adding a field.
- Example: "Turn on lightweight migration for the new field."
