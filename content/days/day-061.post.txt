📱 iOS Daily English - Day 61

ArraySlice
- A view into part of an array, made with a range, that shares the array's storage and keeps its original indices.
- Example: "`recent` is an ArraySlice, so its first index isn't zero."

Reserve Capacity
- Calling `reserveCapacity` to set aside room for a number of items before you append them, so the array grows only once.
- Example: "We know there are a thousand rows, so Reserve Capacity first."

ContiguousArray
- An array type that always stores its items side by side in one block of memory, which can make it a bit faster.
- Example: "Switch to ContiguousArray only if Instruments shows the loop is slow."
