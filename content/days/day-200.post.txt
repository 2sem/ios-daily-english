📱 iOS Daily English - Day 200

DecodingError
- The error type that tells you why decoding failed, like a missing key or a wrong type.
- Example: "Print the DecodingError to see which key is missing."

decodeIfPresent
- A decoding method that returns nil instead of failing when a key is missing.
- Example: "Use decodeIfPresent because the nickname can be missing."

Date Decoding Strategy
- A setting that tells the decoder how to turn JSON text into a Date.
- Example: "Set a date decoding strategy for the ISO dates."
