📱 iOS Daily English - Day 128

Parent View Controller
- A view controller that holds other view controllers inside its own screen.
- Example: "The Parent View Controller owns the header and the list."

Child View Controller
- A view controller whose view lives inside another view controller.
- Example: "Make the header a Child View Controller to keep the screen small."

View Controller Containment
- The set of steps that adds a child view controller to a parent safely.
- Example: "Follow View Controller Containment, or the child will not get its events."
