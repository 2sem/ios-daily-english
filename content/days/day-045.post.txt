📱 iOS Daily English - Day 45

Value Semantics
- A behavior where every copy of a value is independent, so changing one copy never changes another.
- Example: "Arrays have Value Semantics, so changing `b` won't touch `a`."

Copy-on-Write
- An optimization where copies share the same storage until one of them is changed.
- Example: "Copying the big array is cheap, thanks to Copy-on-Write."

isKnownUniquelyReferenced
- A Swift function that returns true when only one strong reference points to a class instance.
- Example: "Check isKnownUniquelyReferenced before you write to the shared buffer."
