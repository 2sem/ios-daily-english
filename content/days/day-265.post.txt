📱 iOS Daily English - Day 265

MainActor
- A special actor that runs its code on the main thread, where UI work belongs.
- Example: "Mark the view model with MainActor."

Nonisolated
- A keyword that lets an actor's member run without isolation, so callers do not need `await`.
- Example: "Make the label property nonisolated."

Global Actor
- An actor that you can attach to many types and functions, so all of them run in one shared place.
- Example: "A global actor can protect code across many files."
