📱 iOS Daily English - Day 238

Sensitive Data
- Personal or secret information, such as an email address or a password, that must be protected.
- Example: "Never print sensitive data in a log."

Redaction
- Hiding part of a message, so the log shows a placeholder instead of the real value.
- Example: "Redaction replaces the email with a placeholder."

OSLogPrivacy
- The option type whose values, such as public and private, control how a value in a log message is shown.
- Example: "Mark the user id private with OSLogPrivacy."
