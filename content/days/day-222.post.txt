📱 iOS Daily English - Day 222

Private Database
- The CloudKit database that only the signed-in user can read, and it uses that user's iCloud storage.
- Example: "Personal notes belong in the private database."

Record Zone
- A named group of records inside a database, which helps CloudKit track changes.
- Example: "Create a record zone called Notes for the user."

CKSubscription
- A request that asks CloudKit to send a push message when matching records change.
- Example: "Add a CKSubscription so the other device hears about new notes."
