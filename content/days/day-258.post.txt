📱 iOS Daily English - Day 258

Async Function
- A function marked `async` that can pause while it waits for a result.
- Example: "Mark the function as an async function."

Await
- A keyword that marks where an `async` call may pause until its result is ready.
- Example: "Add await before the call."

Suspension Point
- A place in `async` code where the function may pause and let other work run.
- Example: "Each await is a suspension point."
