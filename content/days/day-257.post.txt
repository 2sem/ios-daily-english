📱 iOS Daily English - Day 257

Block Operation
- A ready-made operation that runs one or more blocks of code when it starts.
- Example: "Wrap the work in a block operation."

Operation Queue
- A queue that runs operation objects and lets you set how many run at once.
- Example: "Add the work to the operation queue."

Operation Dependency
- A rule that makes one operation wait until another operation has finished.
- Example: "An operation dependency keeps the right order."
