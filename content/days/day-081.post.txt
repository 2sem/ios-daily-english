📱 iOS Daily English - Day 81

Launch Screen
- The static screen iOS shows while your app is starting, before your first real screen appears.
- Example: "Make the Launch Screen look like the first screen, so the start feels fast."

App Delegate
- The object that receives app-wide events from iOS, like the moment launch finishes.
- Example: "Put the analytics setup in the App Delegate, it only needs to run once at launch."

Scene Delegate
- The object that handles the events of one window of your app, like going to the background.
- Example: "The Scene Delegate saves the draft when the user leaves the app."
