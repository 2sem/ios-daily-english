📱 iOS Daily English - Day 12

throws
- A keyword you add to a function to say that it can fail and send back an error.
- Example: "I marked the save function as throws, because writing to disk can fail."

try
- A keyword you write before a call to a function that can fail, to show you know it might send back an error.
- Example: "You need to put try before that call, otherwise the compiler will complain."

do-catch
- A statement that runs code that might fail and lets you handle the error if one happens.
- Example: "I wrapped the decoding in a do-catch, so a bad response will not crash the app."
