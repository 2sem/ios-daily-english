📱 iOS Daily English - Day 12

Stored Property
- A variable or constant inside a type that keeps its own value.
- Example: "Make `name` a stored property, so each user keeps their own name."

Computed Property
- A property that does not keep a value and works out its result each time you read it.
- Example: "Make `total` a computed property, so it always matches the price and quantity."

Property Observer
- Code that runs right before or after a property changes its value.
- Example: "Add a property observer, so the label updates when the score changes."
