📱 iOS Daily English - Day 269

Actor Hop
- A switch of a task from one actor's executor to another when it awaits a call on that actor.
- Example: "Each actor hop costs a little time."

Isolated Parameter
- A function parameter marked `isolated`, so the function runs inside that actor's isolation.
- Example: "Make it an isolated parameter to skip the await."

Sending Parameter
- A parameter marked `sending`, which hands the value over so the caller cannot use it afterward.
- Example: "Pass a new object through a sending parameter."
