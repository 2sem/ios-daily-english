Protocol Composition
- Joining protocols with an ampersand, like `Named & Aged`, so a value must conform to all of them.
- Example: "Use Protocol Composition here instead of one giant protocol."

Class Only Protocol
- A protocol that inherits from `AnyObject`, so only classes can adopt it and you can hold it weakly.
- Example: "Make the delegate a Class Only Protocol, so we can store it as `weak`."

Self Requirement
- A protocol requirement that uses `Self`, meaning the exact type that adopts the protocol.
- Example: "Because of the Self Requirement, `mix` only accepts the same type."
