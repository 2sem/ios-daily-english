📱 iOS Daily English - Day 30

Protocol Extension
- An extension that adds methods or computed properties to every type that adopts a protocol.
- Example: "I added a protocol extension on `Greeter`, so all our greeting types get `greet()` for free."

Default Implementation
- A method body in a protocol extension that a conforming type uses when it does not write its own.
- Example: "`Square` doesn't write `describe()`, so it falls back to the default implementation."

Associated Type
- A placeholder type name inside a protocol that each conforming type fills in with a real type.
- Example: "The protocol uses an associated type for `Item`, so each box decides what it stores."
