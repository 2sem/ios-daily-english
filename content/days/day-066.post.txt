📱 iOS Daily English - Day 66

Enum Case Pattern
- A pattern like `.circle(let r)` that matches one enum case and pulls out its associated values.
- Example: "Use an Enum Case Pattern in `if case`, you don't need a full `switch` here."

Recursive Enum
- An enum with a case that holds a value of the same enum, like a folder that holds folders.
- Example: "The comment thread is a Recursive Enum, so replies can hold replies."

Indirect Enum
- An enum, or a single case, marked `indirect`, so Swift stores the nested values behind a pointer.
- Example: "Make it an Indirect Enum, otherwise the compiler can't work out its size."
