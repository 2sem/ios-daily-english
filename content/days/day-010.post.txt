📱 iOS Daily English - Day 10

Protocol
- A list of requirements that a type promises to follow, without saying how the work is done.
- Example: "Let's write a protocol for the data service, so we can swap in a fake one in tests."

Protocol Conformance
- When a type promises to follow a protocol and provides everything that the protocol asks for.
- Example: "I added Codable conformance to the model, so we can save it as JSON."

Extension
- A way to add new features to an existing type, even one you did not write yourself.
- Example: "I wrote an extension on String to trim spaces, and now we use it everywhere."
