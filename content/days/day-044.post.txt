Opaque Type
- A return type written with `some` that hides the real type but keeps it the same every time.
- Example: "`body` returns an Opaque Type, so we never write the long view type."

Existential Type
- A type written with `any` that can hold a value of any type that conforms to a protocol.
- Example: "The array needs an Existential Type because it mixes squares and dots."

Type Erasure
- A technique that wraps different concrete types in one common type so they can be used the same way.
- Example: "`AnyHashable` uses Type Erasure, so one set can hold an `Int` and a `String`."
