Function Type
- The type of a function, written with an arrow like `(Int) -> Int`, so you can store a function in a variable.
- Example: "Make the handler's Function Type `(String) -> Void`, not `Any`."

Currying
- Turning a function with several parameters into a chain of functions that each take one argument and return the next function.
- Example: "With Currying, we set the tax rate once and reuse the function."

Function Composition
- Joining two functions into a new one, where the output of the first becomes the input of the second.
- Example: "Use Function Composition to chain the price steps into one function."
