📱 iOS Daily English - Day 167

UIHostingController
- A view controller that shows a SwiftUI view inside a UIKit app.
- Example: "Wrap the new screen in a UIHostingController."

UIViewRepresentable
- A protocol that wraps a UIKit view, so you can use it inside SwiftUI.
- Example: "Wrap the map in a UIViewRepresentable."

Coordinator
- An object inside a representable that receives UIKit delegate calls and talks back to SwiftUI.
- Example: "Add a Coordinator to handle the delegate callbacks."
