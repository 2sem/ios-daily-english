📱 iOS Daily English - Day 70

Fatal Error
- A call to `fatalError` that always stops the app, in every build, for code that should never be reached.
- Example: "That `default` case can't happen, so a Fatal Error with a clear message is fine."

Assertion
- A check written with `assert` that stops the app when its condition is false, but only in debug builds.
- Example: "Add an Assertion here, so we notice the bad value while testing."

Precondition
- A check written with `precondition` that stops the app when its condition is false, even in release builds.
- Example: "A wrong index would corrupt the data, so use a Precondition, not an assert."
