📱 iOS Daily English - Day 19

Any
- A type that can hold a value of any type, so one array can mix numbers and text.
- Example: "Use `[Any]` here, because the array holds both numbers and text."

Type Casting
- A way to check the type of a value, or to treat it as another type, using `is` and `as?`.
- Example: "Use type casting to check whether this value is a `String` first."

Downcasting
- A way to treat a value as a more specific type with `as?`, which gives nil if the cast fails.
- Example: "Use downcasting to get an `Int` out, and handle nil if it fails."
