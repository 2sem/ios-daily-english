📱 iOS Daily English - Day 267

Task Sleep
- A call that pauses the current task for a set time without blocking its thread.
- Example: "Use task sleep to wait one second."

Task Yield
- A call that lets the current task step aside so other tasks can run first.
- Example: "Call task yield inside a long loop."

Task Local Value
- A value that is attached to a task and can be read by its child tasks.
- Example: "A task local value follows the child tasks."
