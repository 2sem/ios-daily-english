📱 iOS Daily English - Day 208

Authorization Header
- A request header that carries the credentials that prove who you are.
- Example: "Add the authorization header to every request."

Bearer Token
- A secret string that a request sends to prove the user is logged in.
- Example: "Never print the bearer token in the logs."

OAuth
- A standard that lets users sign in with another service without sharing their password.
- Example: "We use OAuth for the Google sign-in."
