📱 iOS Daily English - Day 224

Memory Cache
- A fast cache that keeps items in RAM, but it empties when the app closes.
- Example: "The memory cache shows the avatar right away."

Disk Cache
- A cache that saves items in files, so they survive an app restart but load more slowly.
- Example: "The disk cache keeps images after a restart."

Cache Key
- A unique name that you use to store and find one item in a cache.
- Example: "Use the image URL as the cache key."
