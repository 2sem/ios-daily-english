📱 iOS Daily English - Day 196

State Management
- The way an app stores and updates the data that its screens show.
- Example: "Our state management is simple: one struct holds everything."

Unidirectional Data Flow
- A design where data moves in one direction and every change starts from an action.
- Example: "Unidirectional data flow makes the bug easy to trace."

Reducer
- A function that takes the current state and an action and returns the new state.
- Example: "The reducer returns a new state for every action."
