📱 iOS Daily English - Day 125

Pasteboard
- A shared place where the system keeps copied data, so you can paste it in another app.
- Example: "Write the invite link to the Pasteboard when the user taps Copy."

Drag Interaction
- An object you add to a view so that the user can pick it up and drag it.
- Example: "Add a Drag Interaction so users can drag the photo to another app."

Drop Interaction
- An object you add to a view so that it can accept something the user drops on it.
- Example: "Add a Drop Interaction to accept files from the Files app."
