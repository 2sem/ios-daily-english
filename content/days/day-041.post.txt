Property Wrapper
- A type marked with `@propertyWrapper` that adds the same extra logic to every property it is attached to.
- Example: "Let's write a Property Wrapper so every name is stored in capitals."

Wrapped Value
- The value inside a Property Wrapper that you read and write through the property's normal name.
- Example: "When you read `count`, you get the Wrapped Value, not the wrapper."

Projected Value
- An extra value a Property Wrapper can expose, which you reach with a dollar sign before the property name.
- Example: "`$score` is the Projected Value, so it's not the score itself."
