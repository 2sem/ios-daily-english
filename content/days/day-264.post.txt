📱 iOS Daily English - Day 264

Actor
- A type that protects its own data by letting only one task use it at a time.
- Example: "Use an actor to protect the shared counter."

Actor Isolation
- The rule that only code inside an actor can touch its data directly, while others must use `await`.
- Example: "Actor isolation forces other code to use await."

Reentrancy
- A behavior where an actor can run other calls while one call waits at an `await`, so its state may change.
- Example: "Reentrancy means state can change at an await."
