📱 iOS Daily English - Day 5

Array
- A collection that stores values in order and lets you read each one by its position.
- Example: "The array keeps the tags in order, so the screen looks right."

Dictionary
- A collection that links each unique `key` to a `value`, so you can look up data by name.
- Example: "Store the tag colors in a dictionary, with the tag as the `key`."

Set
- A collection that stores unique values in no particular order and ignores duplicates.
- Example: "Turn the list into a set, and the duplicate tags are gone."
