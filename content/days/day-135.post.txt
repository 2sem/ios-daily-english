📱 iOS Daily English - Day 135

State
- A property wrapper that lets a view store a value and redraw when it changes.
- Example: "Store the counter in State, so the screen updates."

Binding
- A two-way link to a value that another view owns.
- Example: "Pass a Binding to the child view, so it can edit the name."

Source of Truth
- The one place that owns a value, so every other view reads it from there.
- Example: "The parent view is the Source of Truth for the name."
