📱 iOS Daily English - Day 8

Enum
- A type that lists a fixed set of related choices, such as north, south, east and west.
- Example: "I made an enum for the screen states, so the code can only be loading, loaded or failed."

Raw Value
- A fixed value, such as a string or a number, that is attached to each case of an enum when you declare it.
- Example: "I gave each case a string raw value, so it matches the name the server sends."

Associated Value
- Extra data that you attach to an enum case when you create it, so each case can carry different details.
- Example: "The failed case has an associated value for the error, so we can show the right message."
