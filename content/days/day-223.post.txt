📱 iOS Daily English - Day 223

Cache Hit
- A moment when the data you need is already in the cache, so no slow work is needed.
- Example: "A cache hit makes the profile load instantly."

Cache Miss
- A moment when the data is not in the cache, so the app must load it the slow way.
- Example: "On a cache miss, we call the server."

Time to Live
- How long a cached item stays valid before it counts as too old.
- Example: "Set the time to live to sixty seconds."
