📱 iOS Daily English - Day 37

Reference Type
- A type whose instances are shared, so copying a variable gives you a second name for the same object.
- Example: "`Player` is a Reference Type, so updating `copy` also updated `original`."

Identity Operator
- An operator, written as three equals signs, that checks if two references point to the same object.
- Example: "Use the Identity Operator to check it's the same `Player`, not just an equal one."

AnyObject
- A protocol that every class conforms to automatically, so you can use it to allow only class instances.
- Example: "I added AnyObject to `Listener`, so structs can't adopt it anymore."
