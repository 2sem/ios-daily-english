📱 iOS Daily English - Day 47

Lazy Property
- A stored property marked `lazy` whose value is created only when it is first used.
- Example: "Make `formatter` a Lazy Property, so launch doesn't pay for it."

Lazy Sequence
- A sequence that runs operations like `map` only when each element is actually needed.
- Example: "With a Lazy Sequence, we stop filtering once we have ten posts."

Memoization
- A technique that saves the result of a function call so the same input is not calculated twice.
- Example: "Add Memoization, so each thumbnail size is calculated only once."
